# Brand creation skills

**Standardize the process, not the personality.**

A practical human–agent workflow for finding a brand's character without replacing it with the model's favourite website template.

Start with what is true: beliefs, behaviour, niche tastes and contradictions. Collect references with reasons. Research neighbouring brands. Explore different premises, refine deliberately, test meaning and accessibility, then deliver a usable `/brand` reference.

## What is here

One portable entry-point skill, with four focused stage guides rather than five overlapping installations:

- **Discovery:** beliefs, niche interests, optional Pinterest/reference boards, audience evidence and peer research.
- **Directions:** visual and verbal exploration, optional naming, controlled comparisons and scoped approvals.
- **Validation:** interpretation, preference, recognition, real applications, contrast and other accessibility checks.
- **Delivery:** approved assets, voice, templates, tokens and matching human/agent documentation at `/brand`.

There are seven original worksheets plus a project-state template. No private project data or restricted source templates are included.

## Use it

Clone this repository:

```sh
git clone https://github.com/simonvanlaak/brand-creation-skills.git
```

Ask your agent:

> Read `skills/brand-creation/SKILL.md` and follow its linked stage guides. Help me develop a brand. Start by learning what is already true; do not start with a logo or website. Keep working notes private and ask before publication.

If your agent supports `SKILL.md` packages, copy the **entire** `skills/brand-creation` directory into its documented skill directory. Keep the relative paths intact. Do not overwrite an existing package without comparing it first. Otherwise the Markdown works as a manual process with any assistant—or with no assistant at all.

This repository contains instructions, not an installer, runtime integration or executable brand generator. No model/provider subscription is required by the package itself. Any tools used during a project retain their own requirements and costs.

## What it refuses to automate away

The human owns conviction and taste. Audience research tells us how work is received; it does not vote a personality into existence. The agent researches, challenges, produces alternatives, records decisions and checks execution.

Values need not be unique to matter. Differentiation is not the same as recognition. A new brand cannot have years of learned recognition on day one. AI imagery is optional, not an obligatory first step. A successful contrast check does not mean a design is good—or fully accessible.
