# System and delivery checklist

Status: blank worksheet. Copy into a private project before filling it in.

- Approved masters and exact token values; proposed/superseded assets separated.
- Actual colour pairs, ratio/tool, text size/use, theme/state and pass/fail; unresolved failures visible.
- Representative reading/mobile/slide/product specimens as relevant.
- Keyboard, focus, resizing/reflow, non-colour cues, reduced-motion and font-loading evidence.
- Belief-to-experience check on an actual touchpoint.
- Font/image/asset licences and permitted redistribution scope.
- Private research excluded; public copy approved.
- Human docs, Markdown, CSS/JSON and downloads agree.
- Editable templates open; live routes/downloads work.
- Version, owner, approval date, changes and unresolved limitations recorded.
